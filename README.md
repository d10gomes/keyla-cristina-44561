# Keyla Cristina 44561 — Landing Page

Landing page de campanha de Keyla Cristina, candidata a Deputada Estadual pela Bahia
(44561, União Brasil). React + TypeScript + Vite + Tailwind CSS v4.

Veja o [`CLAUDE.md`](./CLAUDE.md) para detalhes completos do projeto, decisões de
conformidade (TSE/LGPD) e estrutura de arquivos.

## Rodando localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```
